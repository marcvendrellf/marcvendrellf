## Projects

### Prog Correction Helper

VS Code extension and Python analysis engine for assisting the correction of C assignments. It checks configurable coding standards, reports line-level feedback, and helps teaching assistants correct more consistently while reducing review time.

### ProgCoordinationManager

End-to-end automation pipeline for university course coordination. It consolidates Moodle and CodeRunner data, applies grading rules, and turns thousands of submissions into final marks with less manual work.

### Dearly

Personal video diary system for organizing, transcribing, enriching, and searching large libraries of personal clips. Built around local-first principles, transcript pipelines, metadata generation, and retrieval.

### SmartTruck

AI-powered delivery route optimizer built during InterHackBCN, a 36-hour interuniversity hackathon with 400 students. Our team won 3rd place in the DAMM Challenge; I worked on data visualization and frontend-backend integration.
